# Колесо фортуны для amoCRM (oficegameF5)

Геймификация отдела продаж: менеджер переводит сделку в этап «Успешно реализовано» —
получает 1 коин. Коин = один прокрут колеса фортуны. Призы и шансы настраивает админ.

## Как это работает

1. В amoCRM настроен вебхук «Статус сделки изменён» на URL
   `http://89.169.3.47:8000/webhook/amocrm`.
2. Сервер видит, что сделка впервые оказалась в статусе успеха (`status_id = 142`),
   и начисляет ответственному менеджеру 1 коин. Повторно за ту же сделку коин не начисляется.
3. Менеджер заходит на `http://89.169.3.47:8000/`, логинится своей почтой из amoCRM
   (пароль = та же почта) и крутит колесо.
4. Приз выбирает сервер криптостойким рандомайзером (`secrets.randbelow`),
   пропорционально процентам из админки. Сумма процентов не обязана быть 100 —
   веса пересчитываются пропорционально. Приз с шансом 0 скрывается из колеса.
5. Админы (список `admins` в `config.json`) видят вкладку «Админ»:
   редактор призов и шансов, баланс менеджеров, полная история прокрутов,
   кнопка синхронизации пользователей из amoCRM.

## Файлы

- `app.py` — сервер на чистой стандартной библиотеке Python 3 (без зависимостей), SQLite.
- `index.html` — страница: логин, колесо на canvas, вкладка админа.
- `config.example.json` — шаблон конфига. На сервере лежит живой `config.json`
  (в git не коммитится, см. `.gitignore`).

## Деплой

Автодеплой через GitHub Actions (`.github/workflows/deploy.yml`):
каждый push в `main` копирует `app.py` и `index.html` на сервер
`/home/kotusov/projects/pr1/` и перезапускает приложение на порту 8000.

Для работы workflow в репозитории нужны секреты
(Settings → Secrets and variables → Actions):

- `F5_SSH_KEY` — приватный SSH-ключ для доступа на сервер (пользователь `kotusov`).

Ручной запуск на сервере:

```bash
cd /home/kotusov/projects/pr1
python3 app.py   # слушает 0.0.0.0:8000
```

## Подключение amoCRM

1. Настройки → Интеграции → создать интеграцию, получить `client_id`/`client_secret`,
   выдать токены и прописать их в `config.json` на сервере вместе с поддоменом аккаунта.
2. Включить вебхук «Статус сделки изменён» на `http://89.169.3.47:8000/webhook/amocrm`.
3. После этого сервер сам подтянет менеджеров (или кнопка «Синхронизировать» в админке).
