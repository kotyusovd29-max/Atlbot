# Пакеты документов ТТН

Водитель в Telegram-боте отправляет пакет из двух документов: ТТН погрузки и ТТН отгрузки.
Они появляются на странице `https://pr1.kotusov.f5-vibe.ru/` с фильтром по водителю и дате.

## Бот

Кнопка «Отправить новый пакет документов», затем фото или файл ТТН погрузки, затем фото или файл ТТН отгрузки.

Токен бота лежит только в `config.json` на сервере. В git его нет.
Деплой записывает токен из секрета GitHub `BOT_TOKEN`.
Сообщения бот забирает сам через Telegram, отдельный адрес webhook не нужен.

## Файлы

- `app.py` — страница и webhook Telegram, стандартная библиотека Python 3, SQLite.
- `index.html` — список пакетов.
- `run.sh` — порт nginx (`8101`), перезапуск, проверка `https://pr1.kotusov.f5-vibe.ru/api/health`.
- `config.example.json` — шаблон. Живой `config.json` не коммитится.

Документы лежат в `uploads/` на сервере и в git не попадают.
Первый деплой этой версии очищает старое содержимое `/home/kotusov/projects/pr1`.
Следующие деплои код обновляют, базу и файлы оставляют (метка `.ttn`).

## Секреты Actions

- `F5_SSH_KEY` — приватный ключ `~/.ssh/f5_team`
- `F5_SSH_PASSPHRASE` — пароль этого ключа
- `BOT_TOKEN` — токен Telegram-бота
